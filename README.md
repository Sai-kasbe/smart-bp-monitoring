# 🩺 Smart Blood Pressure Monitoring Dashboard

A Machine Learning-powered web application that estimates blood pressure using personal health indicators such as Age, Weight, Height, BMI, and Heart Rate.

## 🚀 Live Demo

**Application:** https://smart-bp-monitoring-vxv6zrd6nkjqnrwgnemakf.streamlit.app/

## 📌 Project Overview

The Smart Blood Pressure Monitoring Dashboard is an interactive healthcare analytics application developed using Python, Streamlit, and Scikit-Learn.

The system predicts systolic and diastolic blood pressure values based on user-provided health metrics and presents the results through an intuitive dashboard with health insights and visualizations.

## ✨ Features

* Blood Pressure Estimation
* Automatic BMI Calculation
* Health Status Classification
* Personalized Health Insights
* Prediction History Tracking
* Feature Importance Visualization
* Interactive Dashboard Interface
* Machine Learning Integration
* Real-Time Predictions

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-Learn
* Random Forest Regressor

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
